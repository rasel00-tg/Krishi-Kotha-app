# কৃষি কথা – এডমিন কন্ট্রোল প্যানেল (Krishi Kotha Admin Control)

একটি স্বতন্ত্র, মাল্টিপ্ল্যাটফর্ম এবং রিয়েল-টাইম **Flutter Admin Portal**, যা বর্তমানে লোকালহোস্টে ওয়েব ড্যাশবোর্ড হিসেবে এবং পরবর্তীতে সরাসরি অ্যান্ড্রয়েড ও আইওএস মোবাইল অ্যাপ হিসেবে বিল্ড করার উপযোগী করে তৈরি করা হয়েছে।

---

## 🚀 লোকালহোস্টে রান করার নিয়ম (Port: 5000)

মূল ইউজার অ্যাপের সাথে পোর্ট কনফ্লিক্ট এড়াতে এটি **পোর্ট ৫০০০ (Port 5000)**-এ কনফিগার করা হয়েছে।

### পদ্ধতি ১: Flutter Web টার্মিনাল কমান্ড
এডমিন ফোল্ডারে টার্মিনাল ওপেন করে রান করুন:
```bash
cd "Krishi Kotha-Admin Control"
flutter pub get
flutter run -d chrome --web-port=5000
```
অথবা হেডলেস / যেকোনো ওয়েব ব্রাউজারের জন্য:
```bash
flutter run -d web-server --web-port=5000
```

### পদ্ধতি ২: এক ক্লিকে রান (Windows Shortcut)
- **`run_admin_web.bat`** ফাইলে ডাবল ক্লিক করুন।
- অথবা PowerShell এ রান করুন:
  ```powershell
  .\run_admin_web.ps1 -Port 5000
  ```

### 🌐 সরাসরি লোকালহোস্ট প্রিভিউ লিংক:
👉 **[http://localhost:5000/](http://localhost:5000/)**

## 📱 ভবিষ্যতে মোবাইল অ্যাপ হিসেবে বিল্ড করার নিয়ম

প্রোজেক্টটির কোডবেস `LayoutBuilder` ও `ResponsiveLayout` আর্কিটেকচারে সাজানো। তাই এটি ভবিষ্যতে যেকোনো সময় মোবাইল অ্যাপে বিল্ড করা যাবে:

### Android APK বিল্ড:
```bash
cd "Krishi Kotha-Admin Control"
flutter build apk --release
```

### iOS বিল্ড:
```bash
flutter build ios --release
```

## 🛠 আর্কিটেকচার ও মূল ফিচারসমূহ

১. **ড্যাশবোর্ড সামারি (Real-time Overview):**
   - নিবন্ধিত কৃষক সংখ্যা, সক্রিয় বাজার দর পণ্য, নথিভুক্ত ফসল এবং প্রচারিত নোটিফিকেশনের লাইভ রিয়েল-টাইম মেট্রিক্স।

২. **লাইভ নোটিফিকেশন ম্যানেজমেন্ট:**
   - কৃষকদের জন্য জরুরি আবহাওয়া সতর্কতা, ফসল পরামর্শ বা সাধারণ নোটিশ সরাসরি ব্রডকাস্ট করার ফর্ম।
   - প্রচারিত নোটিফিকেশন তালিকা দেখা ও মোছার সুবিধা।

৩. **বাজার দর আপডেট কন্ট্রোল (Market Prices):**
   - বিভিন্ন জেলা ও হাটের কৃষিপণ্যের পাইকারি ও খুচরা দর ইনপুট ও আপডেট।
   - দরের ট্রেন্ড (উর্ধ্বমুখী / নিম্নমুখী / স্থিতিশীল) নির্ধারণ।
   - জেলাভিত্তিক রিয়েল-টাইম ফিল্টারিং।

৪. **ফসল ও বালাই ব্যবস্থাপনা (CRUD Operation):**
   - নতুন ফসল, জাত, উপযোগী মাটি ও বপন সময় যুক্ত/সম্পাদনা।
   - ফসলের রোগবালাই, লক্ষণ, জৈব প্রতিকার ও রাসায়নিক দমন ব্যবস্থার সম্পূর্ণ CRUD।

৫. **কৃষক ও সহায়তা টিকিট মনিটরিং:**
   - নিবন্ধিত কৃষকদের প্রোফাইল, ফোন ও পছন্দের ফসল মনিটরিং।
   - কৃষকদের করা প্রশ্ন/সহায়তা টিকিটের সরাসরি উত্তর প্রদান ও সমাধান।
